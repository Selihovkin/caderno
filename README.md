# Caderno

Бесплатные конспекты по европейскому португальскому (PT-PT) для русскоязычных.

Сайт статический: при каждом изменении в ветке `main` GitHub сам собирает его и публикует на GitHub Pages (это делает `.github/workflows/deploy.yml`). Через минуту-две после изменения новая версия уже на сайте.

## Как устроен проект

```
src/
  lessons/        уроки, по одному файлу на урок (01-…, 02-…)
    _template.html  шаблон нового урока (на сайт не попадает)
  pages/          главная, список уроков, страница 404
  layouts/        общая шапка, подвал и оформление страницы урока
  site.json       название сайта и уроки «скоро»
assets/
  css/style.css   все стили
  js/site.js      «скрыть переводы», «пройден», оглавление
img/              картинки, по папке на урок
build.js          сборка сайта (только Node.js, без внешних пакетов)
```

## Как добавить урок

1. Скопируйте `src/lessons/_template.html` в новый файл, например `src/lessons/04-ser-e-estar.html`.
2. Заполните шапку между строками `---`: номер, `slug` (часть адреса, только латиница и дефисы), название, описание.
3. Напишите разделы урока. Готовые блоки (примеры с переводом, заметки, таблицы, карточки с картинками) можно копировать из уроков 01–03.
4. Картинки положите в `img/<slug>/` и вставляйте как `/img/<slug>/имя.webp`.
5. Если урок был в списке «скоро», уберите его из `src/site.json`.
6. Сохраните изменения (commit) в ветку `main`. Сайт обновится сам.

Список уроков, нумерация и ссылки «предыдущий / следующий» собираются автоматически.

Файлы можно править прямо на github.com: откройте файл, нажмите на карандаш, внесите правку и нажмите **Commit changes**.

## Как посмотреть сайт у себя на компьютере

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```
node build.js --serve
```

Сайт откроется на http://localhost:8080. После правки файлов перезапустите команду.

## Первичная настройка GitHub Pages

Один раз: в репозитории **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.

Ход публикации виден на вкладке **Actions**. Если сборка упала, там же будет понятное сообщение об ошибке (например, о незаполненном поле в шапке урока).
